| # | Diagram | UML type | What it shows | Source |
|---|---|---|---|---|
| 1 | `out/01_use_case` | Use case | Actors (policyholder, adjuster, admin, connected device, LLM gateway), use cases grouped by role, `«include»` / `«extend»` | `gen_use_case.py` |

## Regenerate

```powershell
cd demo_deck
python render_uml.py          # diagrams 2-8 (Mermaid 10.9.1 from jsDelivr, rendered in headless Edge; needs internet)
python uml/gen_use_case.py    # diagram 1 (drawn directly as SVG)
```

Edit the `.mmd` file and re-run to update a diagram. Mermaid has no native use case notation, which is why diagram 1 is generated by a script.
The `.mmd` files also render in GitHub, VS Code (Mermaid extension) and https://mermaid.live.
